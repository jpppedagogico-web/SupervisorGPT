# 🎓 SupervisorGPT

Assistente Inteligente para Supervisores Educacionais da SEDUC-SP.

O SupervisorGPT utiliza Inteligência Artificial para consultar legislações, resoluções, deliberações, pareceres e demais documentos normativos da Secretaria da Educação do Estado de São Paulo.

---

## Principais recursos

✅ Pesquisa inteligente de normas

✅ Respostas contextualizadas utilizando IA

✅ Busca por artigos

✅ Índice jurídico próprio

✅ Painel administrativo

✅ Atualização automática da base normativa

✅ Base local de documentos
